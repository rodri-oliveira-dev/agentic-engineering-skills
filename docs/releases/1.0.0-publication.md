## Published distribution metadata

The tagged revision includes all ten canonical skills under `.agents/skills/`, the generated package at `plugins/agentic-engineering/`, and these public marketplace manifests:

- `.agents/plugins/marketplace.json` for OpenAI Codex;
- `.github/plugin/marketplace.json` for GitHub Copilot CLI;
- `.claude-plugin/marketplace.json` for Claude Code.

Each marketplace entry and both plugin manifests declare version `1.0.0` and resolve to the generated package containing all ten skills. Repository tests and package checks structurally validate their metadata, confined paths, deterministic contents, and embedded file hashes.

Post-publication validation on 2026-11-23 used Codex CLI `0.171.0-alpha.13` with new isolated `CODEX_HOME` directories. The public `owner/repo` marketplace source registered successfully from both the default branch and explicit `--ref 1.0.0`; each run listed `agentic-engineering@agentic-engineering-skills` version `1.0.0` and installed the plugin into the isolated cache. This validates those specific remote Codex CLI installation workflows; it does not validate the interactive `/plugins` UI, live discovery or activation, model behavior, Copilot CLI, or Claude Code.

## Relationship to the readiness assessment

Publication occurred even though the prerelease assessment recorded the following criteria as pending or blocked at its cutoff. No repository evidence was found that retroactively satisfies them:

- controlled live OpenAI Codex behavioral evaluation;
- live GitHub Copilot and Claude Code behavioral compatibility;
- complete dependency vulnerability and provenance assessment;
- custom immutable release artifacts and release-level checksums;
- recorded maintainer publication approval that explicitly accepted the residual risks.

The tag, GitHub Release, GitHub-generated source archives, and successful exact-commit CI now exist as factual evidence. Approval evidence is not recorded in the repository. Publication is not proof that every original release condition was met, waived, or reviewed.

## Known limitations and outstanding work

- No completed live-agent behavioral evaluation record exists; fixture validation is not execution.
- Codex remote marketplace registration and installation have been observed only with the named CLI and isolated environment. Live skill discovery, automatic or explicit activation, refusal behavior, and output quality remain unverified.
- Copilot CLI and Claude Code marketplace install, update, uninstall, discovery, activation, and behavioral workflows remain unverified because those clients were unavailable in the validation environment.
- The universal `skills` CLI `1.9.0` discovered all ten skills from both a local checkout and the public `owner/repo` source, but no mutating remote installation is recorded. Its current help does not document a stable Git-revision pinning syntax, so no version-pinned command is claimed.
- GitHub CLI remotely previewed one skill, but its mutating install/update workflow was not executed.
- PyYAML `6.0.4` is pinned, but no complete SCA/advisory reachability assessment or comprehensive provenance review is recorded.
- GitHub-generated source archives have no project-published checksums or signatures. Embedded package hashes detect drift but do not authenticate the publisher.
- Marketplace publication does not establish compatibility across every client surface or future client version.

These limitations should remain visible in the [compatibility matrix](../platforms/compatibility-matrix.md), [validation guide](../validation.md), and [roadmap](../roadmap.md) until replaced by attributable evidence.
