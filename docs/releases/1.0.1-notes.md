# Release 1.0.1

## Versão 1.0.1  Esta versão consolida melhorias de segurança, automação de releases e documentação do projeto Agentic Engineering Skills.  ### Melhorias  - Implementação de auditoria automatizada de dependências (SCA) com `pip-audit`. - Geração de SBOM no formato CycloneDX e inventário de proveniência. - Verificação de integridade dos plugins e dos pacotes gerados. - Configuração do Dependabot para dependências Python e GitHub Actions. - Implementação de workflows para preparação e publicação controlada de releases. - Inclusão de geração de checksums SHA-256 e suporte a atestações criptográficas dos artefatos. - Separação das permissões entre auditoria, construção e publicação, com suporte à aprovação por GitHub Environment. - Atualização da documentação de distribuição, segurança e processo de publicação. - Ampliação dos testes automatizados de versionamento e segurança dos workflows.  ### Compatibilidade  As dez Agent Skills existentes foram preservadas, sem alterações funcionais neste ciclo.  ### Validação  Os testes automatizados de Linux e Windows e a auditoria de segurança foram aprovados nos PRs de infraestrutura. O fluxo completo de atestação e publicação será validado durante a primeira release executada pelo novo processo.  ### Referências  - PR #6: Atualização da documentação. - PR #7: Automação da segurança da cadeia de suprimentos. - PR #8: Automação do ciclo de releases.
